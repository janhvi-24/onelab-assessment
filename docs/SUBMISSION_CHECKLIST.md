# Onelab assessment submission checklist

- [ ] Brainstorming: include the actual full LLM thread; `docs/BRAINSTORMING_WORKING_NOTES.md` is a concise working-notes aid, not a substitute for the original thread.
- [ ] Distilled prompt: `docs/COPILOT_DISTILLED_PROMPT.txt`
- [ ] Raw prompt: `docs/COPILOT_RAW_PROMPT.txt` (paste this as one prompt into Copilot Agent mode)
- [ ] Copilot execution thread: paste the complete real conversation into `docs/COPILOT_EXECUTION_LOG_TEMPLATE.md`
- [ ] Test cases: `docs/TEST_CASES.md` and automated tests in `tests/`
- [ ] Working output: deploy to Streamlit Community Cloud; add verified public URL
- [ ] Code zip: provide this repository zip
- [ ] Demo video: record screen using `docs/DEMO_VIDEO_SCRIPT.md`
- [ ] Production limitations: use the three bullets in README, in your own words if desired
